# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-11-22

### Added
- Ten scroll effects: layered parallax, pinned heading, 3D card zoom, line-by-line reveal, sideways text, card arc carousel, fixed 3D model, stacking cards, focus-frame slider, and a scroll-triggered brick tower
- Four original minifig-style characters with tap-to-talk and brick-snap sound
- Mini scenes for the Postcards gallery and the "Pick a world" cards
- Day-to-night hero sky, minifig maker, build-your-own-world baseplate, catch-the-bricks game, and rocket launch finale
- Light and dark color schemes, favicon, and social meta tags
