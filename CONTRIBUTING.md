# Contributing to Brick Park

Thanks for wanting to help! Brick Park is a small, dependency-free project, so contributing is simple.

## Ways to help

- Report a bug or a layout problem (include your browser, device, and a screenshot)
- Suggest a new character, world, or mini game
- Improve accessibility, performance, or documentation

## Getting set up

1. Fork the repo and clone your fork.
2. Run a local server: `python3 -m http.server 8000`
3. Open `http://localhost:8000` and edit `index.html`, `css/style.css`, or `js/main.js`.

There is no build step. Refresh the page to see your changes.

## Guidelines

- Keep the project dependency-free (plain HTML, CSS, and JavaScript).
- Keep all artwork original and made from CSS shapes. Do not add logos, characters, or images from third parties, including official LEGO assets.
- Test on a phone-sized screen and in both light and dark mode.
- Use clear commit messages, for example `feat: add chef character` or `fix: gallery focus on resize`.

## Pull requests

1. Create a branch: `git checkout -b feat/my-change`
2. Make your change and test it.
3. Open a pull request that explains what changed and why. Add a screenshot or short clip for visual changes.
